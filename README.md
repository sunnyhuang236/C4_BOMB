# C4 BOMB：STC89C52RC 无 LCD 版本（安放 + 拆除）

这是给当前这块 **普中 51 实验板 + STC89C52RC** 使用的无屏幕版本。
1602 因板上对比度电路问题暂不使用，倒计时和密码输入全部显示在 **8×8 点阵**上；矩阵键盘、无源蜂鸣器、拆弹逻辑保持不变。

## 游戏流程

### 第一阶段：安放炸弹

上电后点阵显示炸弹图标和 7 个输入进度点，**此时倒计时还没有开始**。

- 安放密码：**7355608**（7 位）
- 输入完成后按 **S11（确认）**
- 密码正确：蜂鸣器提示，**倒计时 60 秒开始**
- 密码错误：点阵短暂显示 X，重新输入
- S12 退格，S13 清空

### 第二阶段：拆除炸弹

倒计时开始后，点阵显示两位秒数和 6 个输入进度点。

- 拆除密码：**000000**（6 位）
- 按 **S11（确认）** 拆除
- 正确：倒计时停止，点阵显示爱心/笑脸，蜂鸣器成功音
- 错误：扣 5 秒，点阵短暂显示 X
- 超时：点阵显示骷髅/X，蜂鸣器警笛

结束后按 **S16** 重新开始，会回到“安放炸弹”阶段，不会自动倒计时。

## 按键

板上丝印是 S1~S16，对应关系如下（从左上到右下）：

```text
S1  S2  S3  S4       0   1   2   3
S5  S6  S7  S8       4   5   6   7
S9  S10 S11 S12      8   9   A   B
S13 S14 S15 S16      C   -   -   D
```

- S1~S10：数字 0~9
- S11：确认（A）
- S12：退格（B）
- S13：清空（C）
- S14、S15：未使用
- S16：结束（拆除/爆炸）后重新开始（D）

### 安放密码 7355608

```text
S8 → S4 → S6 → S6 → S7 → S1 → S9 → S11
 7    3    5    5    6    0    8    确认
```

### 拆除密码 000000

```text
S1 → S1 → S1 → S1 → S1 → S1 → S11
 0    0    0    0    0    0    确认
```

## 倒计时蜂鸣节奏

蜂鸣器接在 **P2.5**，无源蜂鸣器，低电平驱动。倒计时开始后：

| 剩余时间 | 蜂鸣节奏 |
|---|---|
| 大于 30 秒 | 每 2 秒“滴”一声 |
| 10~30 秒 | 每 1 秒一声 |
| 5~10 秒 | 每 0.5 秒一声 |
| 小于等于 5 秒 | 每 0.25 秒双响 |

安放阶段不响倒计时蜂鸣，只有按键声和安放成功提示音。

## 硬件

| 外设 | 引脚 |
|---|---|
| 8×8 点阵 595 SER | P3.4 |
| 8×8 点阵 595 RCLK | P3.5 |
| 8×8 点阵 595 SRCLK | P3.6 |
| 点阵列选 | P0 |
| 4×4 矩阵键盘 | P1.0~P1.7 |
| 无源蜂鸣器 | P2.5 |

板上 595 的 `OE` 跳线（J24 附近）要切到使能位置，点阵才会亮。
如果点阵显示左右/上下反，改 [`User/config.h`](User/config.h) 里的 `MATRIX_FLIP_X` / `MATRIX_FLIP_Y`。

## Keil 编译

1. 打开 `C4_Bomb.uvproj`，Target 选择 `C4_Bomb`。
2. 按 `F7` 编译，应显示 `0 Error(s), 0 Warning(s)`。
3. HEX 在 `Objects/C4_Bomb.hex`。

## 烧录

1. USB 口连接开发板（板载 CH340，COM 口）。
2. STC-ISP 选择 `STC89C52RC`，串口选择 CH340 的 COM 口。
3. 加载 `Objects/C4_Bomb.hex`，晶振选 `11.0592MHz`。
4. 点击下载，然后给开发板断电再上电（冷启动）。

> 如果某个 S 键按了没反应，可能是该按键/焊点本身的问题；先记录实际键位，再改 `Driver/keypad.c` 里的 `s_keymap` 即可。

## 实机验证记录

- 主控识别：STC89C52RC，8KB Flash，11.0592MHz。
- 键盘原始扫描码已通过 USB 串口实测校准，S1~S16 映射与本文一致。
- 安放流程实测：S8→S4→S6→S6→S7→S1→S9→S11 后倒计时正常开始。
- 蜂鸣器实测：倒计时过程中会按 2s→1s→0.5s→0.25s 加速鸣叫。
